# Personal Portfolio of Evidence

A digital Portfolio of Evidence documenting my learning journey, growth and skills throughout the **d-Lab Programme 2026** — built as a website rather than a static document, so each piece of evidence can be explored directly.

## 🌐 Live Demo

[View Live Portfolio](https://nqobile-nkenjane.github.io/Personal-Portfolio-of-Evidence/)

## 📖 What's Inside

This portfolio brings together evidence across the different modules of the programme:

- **Design Thinking** — a live link to my [Design Thinking case study](https://nqobile-nkenjane.github.io/Design-Thinking-Project/), demonstrating the full process from research to prototype
- **Digital Competency** — a Canva-designed "About Me" profile card, a personal finance budget built in Google Sheets, and a Canva presentation on my digital skills and experience
- **Power Skills** — reflections including a vision board and a "saboteur" self-awareness exercise
- **Work Readiness** — evidence of my preparation for the workplace, including a letter to my future self
- **My Learning Journey** — reflections on digital skills, problem-solving, and communication & teamwork developed across the programme
- **Achievements** — my Cisco IT certifications (Cybersecurity, Networking Basics, Computer Hardware Basics, IT Customer Support Basics), viewable directly on the certificates page
- **CV** — my CV, viewable on its own page and available as a PDF

Each section includes short reflection questions and answers, showing not just what I did but what I learned from it.

## 🛠️ Built With

- HTML5 & CSS3
- Vanilla JavaScript (interactive presentation viewer, navigation)
- Google Fonts
- Hosted on GitHub Pages
